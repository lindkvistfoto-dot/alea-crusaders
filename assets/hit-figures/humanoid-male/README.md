# Humanoid male – hit-location illustration pack

Place the eight `.webp` files from `alea-hit-figures-humanoid-male.zip` in this directory: `neutral`, `head`, `chest`, `abdomen`, `left_arm`, `right_arm`, `left_leg`, `right_leg`. All eight have dimensions 512×768 and transparent backgrounds.

Until they are uploaded, the existing anatomical combat hit display is used as a fallback.
