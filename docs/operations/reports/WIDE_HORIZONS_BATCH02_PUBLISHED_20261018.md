# OPERATION WIDE HORIZONS — Batch 02

Date: 2026-10-18. Scope: five skills authorized by the user's “Kör på”. Actual square originals were downloaded from their SHA-256 verified HERMES archives. All five had no WIDE reference or ongoing WIDE job at selection.

Image-based environmental expansion used each actual original as the scene/action/costume reference and the approved photographic woman or elf portrait as the primary identity/material reference. Native 1672×941 PNG images were retained without stretching, cropping or upscaling to exact mathematical 16:9, consistent with the user's amended requirement. Built-in image generation was used; full prompts and source references are recorded in [the production record](WIDE_HORIZONS_BATCH02_PRODUCTION_20261018.json).

## Visual QA

Each output was compared directly with its source: same recognizable performer, costume, action and major landmarks, essential hands and equipment retained. Administrationsjuridik retains the pointing finger and flat wax-sealed documents; Astrologi retains the raised astrolabe and flat star chart; Blåsrör retains the blowing action and small dart; Drogkunskap retains vial, herb bundle and mortar; Gömma sig retains the crouched concealment, rope and complete visible boot. Outpainted scenery is newly synthesized; protected-pixel masking is not exposed by the tool, so immutable source pixels are not claimed. Photorealism and motif fidelity are visual judgments, presented for user review.

Drogkunskap's first draft introduced an unauthorized tent and crates/bowls. That draft failed QA and was never transferred. A targeted correction removed them; only the corrected PNG was published.

## Verification scope

Established HERMES Drive intake → immutable GitHub PNG archive → Actions WebP preparation → private Supabase source/delivery Storage → compare-and-set register activation. No manual Storage upload or SQL activation bypass. Publisher verifies file integrity and SHA-256 through download/readback and a signed delivery URL before activation. Independent SQL checks confirm active jobs, exact source hashes, correct WIDE references, Storage MIME/sizes, active events, and unchanged icons and original illustration paths. Interactive signed-in Alea rendering was not performed; application UI appearance is therefore not independently verified in this batch. No new viewer component or pipeline code was needed.
